<h1>Game Fusion</h1>
<h3>A modern web application that allows users to explore and discover games across different platforms, with advanced filtering, sorting, and search capabilities.</h3>
<br />
<h2>✨ Features</h2>
<ul>
  <li>
    <h3><b>Multi-platform Game Discovery:</b> Browse games from various gaming platforms in one place.<h3>
  </li>
  <li>
    <h3><b>Smart Search:</b> Quickly find specific games with the search functionality.</h3>
  </li>
  <li>
    <h3><b>Advanced Filtering:</b> Sort and filter games by:</h3>
    <ul>
      <h3><li>Platform compatibility</li></h3>
      <h3><li>Genre</li></h3>
      <h3><li>Popularity</li></h3>
      <h3><li>Release date</li></h3>
    </ul>
  </li>
  <li>
    <h3><b>Theme Customization: </b> Switch between light and dark modes for comfortable viewing</h3>
  </li>
  <li>
    <h3><b>Responsive Design:</b> Seamless experience across desktop and mobile devices</h3>
  </li>
</ul>

<h2>📥 Installation</h2>

<h3>1. Clone the repository:</h3>

```bash
git clone https://github.com/sikatanju/game-fusion.git
```
<h3>2. Navigate to the project directory:</h3>

```bash
cd game-fusion
```
<h3>3. Install dependencies:</h3>

```bash
npm install
```
<h3>4. Start the development server:</h3>

```bash
npm run dev
```

<br />

<h2>💻 Usage</h2>

<h3><b>1. Explore Games:</b> Browse through the game library on the home page</p></h3>
<h3><b>2. Filter Content:</b> Use the sidebar filters to narrow down games by platform or genre</p></h3>
<h3><b>3. Search:</b> Utilize the search bar to find specific games</p></h3>
<h3><b>4. Theme Toggle:</b> Switch between light and dark modes using the theme toggle button in the navigation bar</p></h3>
